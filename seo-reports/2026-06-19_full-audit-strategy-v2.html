3. Корінь проблеми (структурний)

Технічне SEO вже зроблено добре (onpage_score 94). Тому подальша «оптимізація titles/meta» нічого не дасть. Реальні корені — три, і всі структурні:

3.1 Нуль авторитету домену

0 посилань, 0 referring domains, 0 згадок бренду у вебі. Молодий домен без беклінків фізично не здатний утримувати позиції за конкурентними запитами. Honeymoon-бонус Google маскував це в лют-березні; коли бонус згас — тримати рейтинг немає чим. Це причина №1 обвалу.

3.2 Тонкий шаблонний контент у масштабі

low_content_rate спрацював на 3618 з 3625 сторінок (~100%). ~4000 сторінок стікерів — майже-дублі: унікального на сторінці лише «sticker #N from Club X, can you identify?», решта — спільний каркас (wiki-врізка, мапа, «інші клуби»). Після оновлень Google 2024+ (scaled content / helpful content) такі масиви знижують якість усього домену, а не лише власні позиції.

3.3 Подвійна невідповідність ніші

  • Інтент: ранжимось по «manchester united sticker», «celtic fc sticker» — це люди, які хочуть купити наліпку. StickerHunt не продає. Конкуренти у видачі — eBay, Redbubble, Etsy, Amazon. Їх не перебити ні авторитетом, ні інтентом.
  • Попит: теми, де StickerHunt справді унікальний (фан-стікер культура, ідентифікація), мають нульовий обсяг пошуку (див. §4.3).

5. SEO-проблеми: повний перелік (Ahrefs + наш краул)

Формат: проблема — масштаб — на що впливає — що робити.

5.1 🔴 Критичні (б'ють у корінь — пріоритет)

C1. Тонкий шаблонний контент на ~4000 sticker-сторінках - Масштаб: low_content_rate 983/989 у краулі. - Вплив: знижує якість усього домену (scaled-content сигнал), розмиває crawl-budget, тягне вниз навіть хороші сторінки. - Дія: консолідувати + noindex окремих sticker-сторінок (залишити багаті club/country/city); або злити стікери в галерею клубу. Рішення Віктора: консолідувати + noindex тонких. ⇒ див. §7 P0.

C2. Нуль беклінків / авторитету - Масштаб: 0 referring domains, 0 згадок бренду. - Вплив: причина №1, чому позиції не тримаються. - Дія: програма link-building з нуля (§7 P1).

5.2 🟡 Бажані (гігієна — робити, але трафік самі не повернуть)

D1. Мульти-meta description (8 тегів <meta name="description"> на сторінку) - Масштаб: 4 155 (Ahrefs); підтверджено curl — по 8 тегів (локалізація через lang, що HTML так не працює). - Вплив: Google читає лише перший, решту вважає сміттям; не критично, але неохайно і марно роздуває HTML. - Дія: лишити один meta description (англ.); багатомовність робити через hreflang + окремі URL або взагалі прибрати lang-дублі. Фікс в одному генераторі ⇒ −4000 «проблем» Ahrefs одним комітом.

D2. Title too long - Масштаб: 211 (краул) / 2 802 (Ahrefs, весь сайт). - Вплив: Google обрізає в видачі — косметика CTR. - Дія: шаблон title ≤ 60 символів у генераторах.

D3. Meta description too short - Масштаб: 4 151 (Ahrefs). - Вплив: низький; впливає на привабливість сніпета. - Дія: підняти дефолтну довжину опису до 110–155 символів у шаблоні.

D4. Missing alt text - Масштаб: 57 (краул) / 56 (Ahrefs). - Вплив: втрата Google Image Search (а зображення стікерів — потенційне джерело трафіку!) + a11y. - Дія: alt = «{Club} football sticker #{N}, {city}» у генераторі.

D5. Render-blocking resources / «Slow page» - Масштаб: 973 стор. render-blocking; Ahrefs «Slow page» 36. Сервер швидкий (TTFB 232мс макс) — проблема суто клієнтська. - Вплив: м'який сигнал CWV; не причина обвалу. - Дія: inline critical CSS, font-display: swap, defer некритичного — частково вже почато (build-critical-css.js).

D6. SEO-friendly URL - Масштаб: 202 (краул) — числові ID /stickers/4.html, /clubs/743.html. - Вплив: URL не несе ключових слів; помірний. - Дія: довгостроково — slug /clubs/celtic-fc.html. Обережно: вимагає 301-редиректів зі старих URL (Chesterton's Fence — не ламати індексацію). Не чіпати в межах антикризового спринту.

D7. Open Graph / Twitter card - Масштаб: OG missing 3, Twitter card missing 3 (Ahrefs); на типових сторінках OG є, але twitter:card відсутній скрізь. - Вплив: вигляд при шері в X/соцмережах; не пошук. - Дія: додати twitter:card=summary_large_image у шаблони.

5.3 🟢 Косметичні (низький пріоритет)

  • no_image_title 983 — атрибут title на зображеннях, на SEO майже не впливає. Можна ігнорувати.
  • no_favicon 3, irrelevant_title 1, no_h1 1, no_description 2 — поодинокі, фікс при нагоді.
  • Duplicate pages without canonical: 3 (Ahrefs) — знайти і додати canonical.

O1. Биті зовнішні лінки — ВЕРИФІКОВАНО curl-ом (не цифри Ahrefs) - Метод: усі 548 club-website URL з wiki-cache перевірено HEAD → підозрілі переперевірено повноцінним GET (браузерні хедери, follow-redirect) → DNS-резолв для «000». O4. Crawl-budget churn (вже частково виправлено) - Знахідка з git: коміти 10.06 — «crawl-budget regression report» + «preserve sitemap lastmod per-URL to stop crawl-budget churn». Sitemap'и регенерувались із новим lastmod на кожен авто-білд ⇒ Google перекраулював незмінні сторінки даремно. - Вплив: марнування crawl-budget, могло погіршувати ситуацію в травні-червні. - Статус: фікс уже в проді (10.06). 7. Перероблена стратегія (v2)

Базовий принцип: технічна гігієна ≠ ріст. Спочатку прибрати quality-drag (тонкі сторінки), потім будувати те, що має попит (квіз) і авторитет (лінки). Стеля органіки в цій ніші об'єктивно низька — тому паралельно тримати не-пошукові канали трафіку.

P0 — Антикризова гігієна + зупинити quality-drag (тиждень 1–2)

  1. Консолідація тонких сторінок (рішення Віктора): noindex,follow на окремих sticker-сторінках АБО злиття у галерею клубу. Лишити в індексі багаті club/country/city. Оновити sitemap (прибрати noindex-URL). ⚠️ Зробити на вибірці, поміряти Crawl Stats, тоді масштабувати.
  2. Фікс мульти-meta (D1) — один опис на сторінку. −4000 «проблем» Ahrefs.
  3. Alt-тексти (D4) — відкриває Image Search (реальний канал для бази фото стікерів).
  4. Titles ≤60 (D2), meta desc 110–155 (D3) — у генераторах.
  5. Почистити биті/http зовнішні лінки (O1, O2).

P1 — Квіз як SEO-продукт (тиждень 2–6) — головний двигун росту

Обґрунтування: єдиний кластер з реальним обсягом І збігом інтенту (§4.3–4.4). 1. SEO-лендінг квізу: окрема сторінка під «football badge quiz» (880) + «guess the football club» (590), з режимами «офіційний бейдж» і «фан-стікер». 2.
