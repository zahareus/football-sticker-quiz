# Докази і опис наявного сайту (станом на 2026-10-25)

Позначки: [Ф] перевірено в джерелі (база, GSC, сторінка); [А] передано агентом-дослідником, незалежно не перевірено; [В] висновок, не факт. Вибірки малі скрізь.

## 1. Наявний сайт (як є)

**Сторінки (корінь репо, статичний HTML + клієнтський JS):** index (головна), catalogue (континент → країна), clubs, map, quiz, battle (оцінювання ТІЛЬКИ парою «батл», ELO), rating, leaderboard, stickerlog («нещодавно додані»), stickerstat (статистика), profile (профіль для квізу), upload / upload-batch / club-create (інтерфейси додавання, лише для Віктора), about, terms, privacy. [Ф]
**Генеровані сторінки (Node-скрипти з шаблонів, CI):** `stickers/<id>.html` (4783), `clubs/<id>.html` (819), `countries/<код>.html` (59), `cities/<slug>.html` (~22+). Сторінка стікера генерується після аплоаду за хвилини; ієрархія країна → клуб → стікер; «також знайдено в місті»; мапа з маркерами (клієнтська); блоки «схожі»; JSON-LD; хлібні крихти. [Ф]
**Стек:** Supabase Pro (Postgres, Auth Google OAuth ≈24 реальних користувачі на червень, Storage, Edge Function, RPC: get_sticker_rank, get_battle_pair, submit_vote, record_quiz_answer), n8n + GitHub Actions для генерації сторінок, хостинг Vercel + GitHub Pages, аналітика GA + PostHog. [Ф]
**База (25.10):** 4783 стікери, 819 клубів (816 зі стікерами), 59 країн. Усі стікери зроблені й додані Віктором. Таблиці: clubs, stickers, scores, votes, profiles (прапорці can_upload, can_edit), user_recent. Колонки stickers: id, created_at, club_id, image_url, difficulty, location, description, found, latitude, longitude, rating, games, wins, losses, last_shown_at, active, quiz_shown_count, quiz_correct_count, view_count. **Колонки автора НЕМАЄ.** Запис: INSERT stickers/clubs лише для `authenticated` з `profiles.can_upload=true`; UPDATE за `can_edit`; anon-запис закрито (серпень 2026). Близько половини стікерів без координат. [Ф]
**Обмеження архітектури:** статичні сторінки печуться генераторами; скрипт сторінки вшитий у кожен HTML; зовнішні `/shared.js`, `/js/view-tracker.js`, `/style.css` кешуються 4 год і дозволяють клієнтський шар без регенерації. Масова регенерація корпусу = ризик для SEO (інцидент травня). [Ф]
**Команда і ресурси:** одна людина (Віктор) + AI-агенти, бюджет малий; модератор лише Віктор. [Ф]

## 5. Референси механік (UGC, ідентифікація, рейтинги, утримання) [А, частково Ф]
- **Додавання/модерація:** MusicBrainz (довіра за лічильником прийнятих правок, авто-прийняття), Discogs (право голосу видається за поведінку; відхилення пояснюють), Geocaching (діалог модератор-автор у чернетці), Wikimedia Commons (patrol/autopatrol), Atlas Obscura (чернетка → submit → блок; «Added by», вкладка «Added» у профілі), IMDb (платна редакція; статус pending). 
- **Ідентифікація:** iNaturalist (Needs ID / Research Grade, понад 2/3 згоди), Vivino (нема збігу → черга ручної ідентифікації, запис потім працює для всіх), Merlin/Seek (модель навчена на підтверджених людьми даних).
- **Антибригейдинг:** RYM (вага голосу, новий акаунт = 0), Steam (авто-детект спайків), Genius (страйки), YouTube (hold-for-review).
- **Утримання:** Letterboxd (оцінка в один тап, watchlist, списки, сторінка веде в рецензії/схожі), Discogs (Collection/Wantlist дві кнопки на кожній сторінці), Collectr (вартість колекції), footballgroundmap (прогрес «відмічено»).
- **Розпізнавання (ціни порядку величини):** Google Vision $1.5–3.5/1000 запитів; CLIP-ембедінги по власному каталогу (працює лише для відомих клубів); для рідкісних стікерів, яких нема в мережі, веб-пошук, найімовірніше, нічого не дасть [В].
- **Права:** друк/PNG зі стікерів — ймовірно комерційне використання чужої графіки; ризик не знімається ні фоном, ні AI-очищенням; юридично НЕ перевірено (ЄС/Україна). [А/В]
