# StickerHunt — Design System (v4, 2026-06)

**Status:** APPROVED, ready for prod implementation. This document is the single source of truth for the site-wide redesign. Implement templates/generators/`style.css` to match it exactly, then regenerate.

**Canonical assets (copied into repo for reference):**
- `docs/design-prototypes/shared.css` — the production CSS (design tokens + all components/plates). The real `style.css` should be rebuilt from this.
- `docs/design-prototypes/*.html` — pixel previews of every page type (generated by `build.cjs` / `build-extra.cjs`, static text by `static-real.py`).

---

## 0. GOLDEN RULES (non-negotiable)

1. **NO INVENTED CONTENT.** Every page mirrors what the REAL current page renders — same headings, fields, controls, copy, data sources, block order. Read the real page (HTML + its JS) before building. Do not add fields, metrics, filters, or text that the live page does not have. Do not hallucinate.
2. **Footer identical on EVERY page** (see §2). No per-page bottom action rows, no bottom site-nav — the sticky top nav + unified footer cover navigation.
3. **Preserve ALL SEO** (see §9). The current site is design-clunky but SEO-rich; nothing in the SEO checklist may be lost.
4. **Corner-case robust** (see §7). Fixed layouts must not break on missing/long/0/many data. Empty sections hide entirely.
5. **Emoji / flags:** real flag IMG (flagcdn or generator flag), never the flag emoji char, in plates and headings (CLS-safe). `H1`/`H2` keep `stripEmoji`. Club plate may show the country flag IMG.
6. **Pagination:** 100 items per page on `rating`, `stickerlog`, `clubs`.

## 1. Design tokens

Street/zine aesthetic on the existing StickerHunt amber brand.

```
--ink:#121212   --ink-2:#3a3a3a   --muted:#7a7a7a
--bg:#fbfaf7    --surface:#ffffff --surface-2:#f0eee8   --line:#121212
--accent:#ffb300 (amber)  --accent-deep:#f08c00  --accent-ink:#3d2c00
--r / --r-sm: 4px   --maxw: 1080px
font: Poppins (self-hosted woff2 400/500/600/700, font-display:block)
shadow: 4px 4px 0 var(--ink)   shadow-sm: 3px 3px 0 var(--ink)   (hard offset, no blur)
```

Look: 2–3px solid `--ink` borders, hard offset shadows, UPPERCASE 800-weight section heads (ink bar w/ bg), amber accents/CTAs, lift-on-hover (`translate(-2px,-2px)` + shadow).

## 3. The 4 plates (visually DISTINCT — never confuse club vs sticker)

| Plate | Class | Shape | Use |
|---|---|---|---|
| **Sticker** | `.sh-st` | SQUARE photo tile (full-bleed image, 1/1, `height:auto`+`aspect-ratio`). Optional foot bar (club name) + optional amber `⚡rating` pill (top-right) + optional rank badge (top-left). Reads as a photo gallery. | sticker grids: more-from-club, similar-from-country, recently added, top rated, gallery, rating, stickerlog |
| **Club** | `.sh-cl` | HORIZONTAL name-led row: 54px sticker-thumb badge (left, amber accent strip) + UPPERCASE club name (with small country flag img) + "{N} stickers". Reads as a list. Placeholder monogram if no image. `.sh-cl.more` = inverted "View all" row. | club grids: country all-clubs, most-collected, catalogue most-collected, clubs page, other-clubs |
| **Country** | `.sh-co` | FLAG-forward: 40×27 flag IMG + country name (line 1) + "{stickers} stickers · {clubs} clubs" (line 2). | catalogue/home browse-by-country |
| **City** | `.sh-ci` | TEXT pin-pill: inline SVG pin + city name + count. Single-line (home/catalogue teaser) or `.sh-ci--col` 2-line (`City` / `Country · N stickers`) on the all-cities index. | browse-by-city, cities index |

**Grids:** `.sh-grid` + `.g6`/`.g4`/`.g3`/`.g7` (mobile collapses to 3 / 2 / 1). `.sh-grid>*{min-width:0}` so 1fr tracks stay equal (long names truncate, never blow out the column → country & city plates align in clean vertical columns).

## 4. Shared components

- **Chips (labeled facts) `.chip`** — `<i>LABEL</i> value` (e.g. `Stadium · Grünwalder Stadion`). Wrap freely; if 0 facts, omit the whole `.chips` block.
- **Metrics `.metric`** — value (1.7rem 800 tabular) + label + optional sub / difficulty meter. `.metrics2` (2-up grid), `.metrics3` (3-up full-width grid). `.metric-link` = clickable cell (amber ↗, hover inverts to ink).
- **Provenance rows `.prov .row`** — icon + text (e.g. `Added <b>date</b>`, `Hunted <b>date</b> · <a>city</a>`); missing → `no data`.
- **Buttons `.btn`** — `.btn-primary` (amber + shadow), `.btn-ghost` (white→ink hover).
- **Section head `.section-head`** — `<h2>` ink bar + optional `.meta` (plain text OR an `<a>` link when it leads to a page).
- **Two-equal-columns `.twocol`** + `.infocard` (stretch), `.kv` labeled list — club info block.
- **Tag block `.tagblock`** — hashtags + links.
- **Map block `.mapblock`** — open (non-collapsing) heading + map area (+ optional View Full Map).
- **About `.about`** — bordered prose card.
- **Pagination `.pag`** — bordered square buttons, current = ink fill, `‹ 1 2 … N ›`.

## 5. Per-page structure (block order = real page; nothing invented)

**Sticker** `/stickers/{id}` — crumb · image (square, overlay ‹ › prev/next faint→amber) · right panel: club H2 + **2 metrics** (Like Rate→rating, Difficulty meter; *Answer Rate removed*) + provenance (Added, Hunted "no data" if empty) + CTA (Play quiz "one of N" + See all N from club) · More-from-club strip (hide if only sticker) · Similar-from-country strip · Map (open, no location label) · About (relocated SEO context paragraph). Fixed-size panel regardless of which facts exist.

**Club** `/clubs/{id}` — crumb · H1 (stripEmoji) · `.twocol`: left card = City/Founded/Stadium/Site (no League); right card = Tags + **Wiki** link only (no URL row; "no data" if no wiki) · About (raised) · **3 full-width metrics** (Stickers / Rank / Top Like Rate) · gallery (all stickers, `.sh-st`) · map · Other clubs (`.sh-cl` + dark "View all N clubs" row). No quiz/locations CTA.

**Country** `/countries/{CC}` — crumb · H1 (flag img) · **3 metrics** (Clubs / Stickers / #rank-by-stickers → catalogue) · Most Collected (`.sh-cl`, 4-up, meta NO arrow) · Featured Stickers (`.sh-st`, meta NO arrow) · **All clubs** (`.sh-cl`, EVERY club, no "view all") · About (SEO).

**Catalogue** `/catalogue` — hero + search (no quick-link buttons) · Recently Added (`.sh-st`, meta link→stickerlog) · Most Rated (`.sh-st`, link→rating) · Most Collected Clubs (`.sh-cl`, 4-up, "720 clubs" plain) · Browse by Country (`.sh-co` grouped by continent) · Browse by City (`.sh-ci`, link→cities) · About (SEO).

**Home** `/` — hero (plain-text stats `2,529 stickers · 715 clubs · 54 countries`) + search · Daily Quiz banner · Recently Added (`.sh-st`, link→stickerlog) · Top Rated (`.sh-st` w/ rating, link→rating) · Discover by Country (`.sh-co`, link→catalogue) · Explore Map preview · Browse by City (`.sh-ci`, link→cities). **No Game Modes block.**

**Cities (all)** `/cities/` — H1 "Cities" + subtitle · `.sh-ci--col` grid (City / Country · N stickers).

**City (one)** `/cities/{x}` — crumb (Catalogue › Cities › City) · H1 "{City}, {Country} — {N} Football Stickers" (count IN heading) · Population fact chip · About (wiki intro + Source: Wikipedia) · 3 info lines (📦 Clubs represented · 📅 First found/Latest · 🌍 Most common: ...) · sticker gallery · Sticker Locations map + View Full Map. *Only what the real page shows — no metric cards.*

**Rating** `/rating` — H1 + "Rate stickers in Battle" CTA · Top rated stickers (`.sh-st` w/ rank badge + ⚡rating, **100/page**, meta "ranked by Like Rate") · pagination.

**Stickerlog** `/stickerlog` — H1 "Sticker Log" + subtitle · date-group sections (h2 per day, **100/page total**) of `.sh-st` plates (club name only, **NO rating** on plate) · pagination.

**Clubs (all)** `/clubs.html` ("Football Sticker Clubs") — hero + search (no quick-links) · "All Clubs / alphabetical · page X of Y" · `.sh-cl` grid (**100/page**, unified plate, NOT a table) · pagination.

**Quiz** `/quiz` — landing: hero + Players stats (top) + Choose a mode (Classic/Time to Run/Hunt Them All cards) + Classic difficulty (Easy/Medium/Hard). game: image + timer bar + lives + score + 4 answer options (2×2; correct/incorrect states). result: GAME OVER + big score box + percentile + Play again/See sticker/Leaderboard. Preserve all script.js hooks.

**Battle** `/battle` — "Which sticker is better?" + "Click on the sticker or press 1 or 2" + total-votes count · two sticker cards (Vote overlay). No skip/stats strip.

**Leaderboard** `/leaderboard` — H1 · time filter (Today/7 Days/All Time) + mode filter (Results/Players) · **4 sections** (Easy/Medium/Hard/Time To Run), each a rank/player/score mini-table.

**Map** `/map` — H1 "Sticker Map" + "Explore N stickers with known locations" + full map. No filters.

**Profile** `/profile` — "⚽ {nick} edit" · Member since / Games played · Best Results (3 cards Easy/Medium/Hard) · Your Last Games (date/difficulty/score rows).

**Stickerstat** `/stickerstat` — H1 · Stickers(N) chart · Clubs(N) "Top 20 clubs by number of stickers" table · Countries(N) "Top 20 countries by number of clubs" table.

**Upload** `/upload` — Club (autocomplete) · Difficulty (1/2/3 buttons) · Sticker Image (JPEG dropzone) · Post to media (checkbox) · Upload. (No location/hashtags.)
**Upload-batch** — dropzone → one row per image (thumb + club autocomplete + difficulty + ✕) → Upload all.
**Club-create** — Club Name · Country Code (3 letters) · "Auto-fill … using AI" checkbox · City,Country · Hashtags · Website URL · Create Club.

**About / Terms / Privacy** — REAL prose verbatim from current pages (about = the 90s-collector story + @StickerHunting; terms = 11 sections; privacy = 9 sections). No invented copy, no bottom CTA/back-link.

## 6. Corner cases (verified via QA variants)

- 0 facts → chip row hidden. 0 hashtags+no web → tag block hidden. No wiki → "no data". No map coords → map block omitted. Empty strip/section → entire section (heading included) omitted.
- 0 stickers → empty-state text, rank/top-rate metrics show "—". 1 sticker → singular "1 sticker", no more-from-club.
- Very long names → H1 wraps; plate names ellipsis/2-line clamp + `title`. Long URLs → display truncated (ellipsis), full in href/title.
- Difficulty falsy → 1. Answer-rate shown=0 → 100%.

## 7. SEO — preserve ALL (from multi-agent inventory)

Per page keep: unique `<title>`, meta description (reused in og/twitter/schema), meta keywords (`buildClubKeywords` + media hashtags), canonical (sticker/club/country self; home `/`; rating `/rating.html`; stickerlog has none — don't add), `MULTILINGUAL_META` (per-lang descriptions + og:locale alternates), full Open Graph + Twitter card set, JSON-LD (sticker ImageObject; club CollectionPage+SportsTeam w/ foundingDate/location/memberOf/3 images; country ItemList of all clubs; home WebSite+FAQPage; BreadcrumbList), single visible H1 (catalogue needs one; sticker H1 stays display:none intentionally), heading hierarchy, the keyword-density context/About paragraphs (sticker context 100–150w, club/country/catalogue About — never shortened), all image alts (multilingual main alt, gallery `{club} street sticker #id`, strip alts), every internal cross-link (breadcrumb, sticker→club/country/city/prev/next, related strips, country↔club, catalogue→all, footer/nav), CWV guards (LCP preload, self-host Poppins, inline critical CSS, `/img/*` proxy + width/height on every image, flags as IMG), analytics (GA4 G-4Y0MJKGDZS, PostHog eu, Amplitude, view-tracker), `replacePlaceholders` fail-fast (keep generators + data objects in sync; pass `test:generators`/`test:placeholders`/`test-country-page-sync`).

Known data bug to flag separately (do NOT silently rewrite): club `city` field sometimes contains the country → "Munich, Germany, Germany". XSS: escape clubName in `title=""` and Supabase errors in rating.js/stickerlog.js. Rating sort needs `.order('id')` tiebreaker.
